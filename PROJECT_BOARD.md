## 📋 Project Board Columns

| Column | Purpose | When to Use |
|--------|---------|-------------|
| **📥 Todo** | New items ready to work on | Issues that are clear and prioritized |
| **🏃 In Progress** | Currently being worked on | When you start working on an issue |
| **👀 Review** | Ready for review/testing | PRs open, needs code review or testing |
| **✅ Done** | Completed items | When issue is closed/merged |

## 🏷️ Labels

### Type
- `bug` - Something is broken
- `feature` - New functionality
- `docs` - Documentation updates
- `refactor` - Code cleanup
- `translation` - i18n work

### Priority
- `critical` - Fix immediately
- `high` - Important
- `medium` - Normal
- `low` - Nice to have

### Status
- `help wanted` - Looking for contributors
- `good first issue` - Good for newcomers
- `blocked` - Waiting on something

## 🎯 Sprint Planning (Simple)

### Monthly Goals
1. Review open issues at month start
2. Assign priorities
3. Pick 3-5 main items to focus on
4. Update board weekly

### Weekly Tasks
- [ ] Review items in "In Progress"
- [ ] Move completed items to "Done"
- [ ] Check for stale items (>30 days)
- [ ] Update priorities if needed
