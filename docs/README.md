## Quick Start

```bash
# Install the theme
./install.sh --update -l -f --dock

# Apply it
./apply-theme.sh
```

## Quick Fixes

| Problem | Solution |
|---------|----------|
| GTK4 apps not themed | `./install.sh -l` |
| Flatpak apps not themed | `./install.sh -f` |
| Dock not styled | `./install.sh --dock` |
| Need to update | `./install.sh --update` |
