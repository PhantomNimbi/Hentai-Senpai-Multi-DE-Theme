## Hintergrundbilder herunterladen

Alle Hintergrundbilder sind im Verzeichnis `wallpapers/` des Repositorys verfügbar. Sie können sie einzeln herunterladen oder das gesamte Repository klonen, um alle zu erhalten.

```bash
# Klonen Sie das Repository, um alle Hintergrundbilder zu erhalten
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Farbpalette

Das Thema verwendet die [Nord-Farbpalette](https://www.nordtheme.com/), mit folgenden Farben:

- **Polar Night** - Dunkle Hintergrundfarben
- **Snow Storm** - Helle Textfarben
- **Frost** - Blaue Akzentfarben
- **Aurora** - Bunte Akzentfarben

Siehe die Seite [Farbpalette](Color-Palette-de-de) für detaillierte Farbinformationen.
