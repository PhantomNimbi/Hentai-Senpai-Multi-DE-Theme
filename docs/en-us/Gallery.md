## Download Wallpapers

All wallpapers are available in the `wallpapers/` directory of the repository. You can download them individually or clone the entire repository to get them all.

```bash
# Clone the repository to get all wallpapers
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Color Palette

The theme uses the [Nord color palette](https://www.nordtheme.com/), featuring:

- **Polar Night** - Dark background colors
- **Snow Storm** - Light text colors  
- **Frost** - Blue accent colors
- **Aurora** - Colorful accent colors

See the [Color Palette](Color-Palette) page for detailed color information.
