## Colores Nord

### Polar Night (Fondos Oscuros)

Los colores de fondo oscuro forman la base de la estética dark del tema.

| Nombre | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord0** | `#2E3440` | 46, 52, 64 | Fondo principal |
| **Nord1** | `#3B4252` | 59, 66, 82 | Fondo más claro, tarjetas |
| **Nord2** | `#434C5E` | 67, 76, 94 | Fondo de selección |
| **Nord3** | `#4C566A` | 76, 86, 106 | Comentarios, texto secundario |

### Snow Storm (Texto Claro)

Estos colores se usan para texto y elementos brillantes.

| Nombre | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord4** | `#D8DEE9` | 216, 222, 233 | Texto principal |
| **Nord5** | `#E5E9F0` | 229, 233, 240 | Texto secundario |
| **Nord6** | `#ECEFF4` | 236, 239, 244 | Texto más brillante, destacados |

### Frost (Azules)

Los tonos azules proporcionan los colores de acento principales.

| Nombre | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord7** | `#8FBCBB` | 143, 188, 187 | Estados de éxito |
| **Nord8** | `#88C0D0` | 136, 192, 208 | Acento principal, información |
| **Nord9** | `#81A1C1` | 129, 161, 193 | Enlaces, acento secundario |
| **Nord10** | `#5E81AC` | 94, 129, 172 | Acento terciario |

### Aurora (Colores de Acento)

Colores vibrantes para errores, advertencias y elementos especiales.

| Nombre | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord11** | `#BF616A` | 191, 97, 106 | Errores, acciones destructivas |
| **Nord12** | `#D08770` | 208, 135, 112 | Advertencias, anotaciones |
| **Nord13** | `#EBCB8B` | 235, 203, 139 | Destacados, tipos |
| **Nord14** | `#A3BE8C` | 163, 190, 140 | Éxito, métodos |
| **Nord15** | `#B48EAD` | 180, 142, 173 | Números, especial |

## Uso en el Tema

### Jerarquía de Fondos

```
Nord0 (#2E3440)  →  Fondo de la ventana principal
    ↓
Nord1 (#3B4252)  →  Fondo secundario, paneles
    ↓
Nord2 (#434C5E)  →  Estados de hover, selecciones
    ↓
Nord3 (#4C566A)  →  Bordes, divisores
```

### Contraste de Texto

```
Nord6 (#ECEFF4)  →  Títulos, texto importante
    ↓
Nord5 (#E5E9F0)  →  Texto del cuerpo
    ↓
Nord4 (#D8DEE9)  →  Texto secundario
    ↓
Nord3 (#4C566A)  →  Texto deshabilitado, placeholders
```

### Uso de Acentos

```
Nord8 (#88C0D0)  →  Botones primarios, enlaces
Nord9 (#81A1C1)  →  Botones secundarios
Nord7 (#8FBCBB)  →  Estados de éxito
Nord14 (#A3BE8C) →  Feedback positivo
Nord11 (#BF616A) →  Errores, destructivo
Nord12 (#D08770) →  Advertencias
Nord13 (#EBCB8B) →  Destacados
```

## Armonías de Color

### Monocromático
Usando variaciones de Nord0-Nord3 para profundidad:
```
Fondo: Nord0
Tarjetas: Nord1
Elevado: Nord2
Bordes: Nord3
```

### Complementarios
Emparejando Frost con colores Aurora:
```
Primario: Nord8 (ciano-azul)
Complemento: Nord12 (naranja)
```

### Análogas
Colores adyacentes para transiciones suaves:
```
Frías: Nord9 → Nord10 (tonos azules)
Calidas: Nord12 → Nord13 (naranja-amarillo)
```

## Variables CSS

Use estas variables en su CSS personalizado:

```css
/* Polar Night */
@define-color nord0 #2E3440;
@define-color nord1 #3B4252;
@define-color nord2 #434C5E;
@define-color nord3 #4C566A;

/* Snow Storm */

@define-color nord5 #E5E9F0;

/* Frost */
@define-color nord7 #8FBCBB;
@define-color nord8 #88C0D0;

/* Aurora */

@define-color nord12 #D08770;

```
