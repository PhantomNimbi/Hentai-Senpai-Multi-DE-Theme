## Descargar Fondos de Pantalla

Todos los fondos de pantalla están disponibles en el directorio `wallpapers/` del repositorio. Puedes descargarlos individualmente o clonar el repositorio completo para obtenerlos todos.

```bash
# Clona el repositorio para obtener todos los fondos de pantalla
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Paleta de Colores

El tema utiliza la [paleta de colores Nord](https://www.nordtheme.com/), que incluye:

- **Polar Night** - Colores de fondo oscuros
- **Snow Storm** - Colores de texto claros
- **Frost** - Colores de acento azules
- **Aurora** - Colores de acento coloridos

Consulta la página [Paleta de Colores](Color-Palette-es-es) para obtener información detallada sobre los colores.
