Le thème Hentai-Senpai utilise la [palette de couleurs Nord](https://www.nordtheme.com/), un schéma de couleurs inspiré des régions polaires conçu pour la clarté et l'élégance.

## Couleurs Nord

### Polar Night (Arrière-plans Sombres)

Les couleurs d'arrière-plan sombre forment la base de l'esthétique sombre du thème.

| Nom | Hex | RVB | Utilisation |
|-----|-----|-----|-------------|
| **Nord0** | `#2E3440` | 46, 52, 64 | Arrière-plan principal |
| **Nord1** | `#3B4252` | 59, 66, 82 | Arrière-plan plus clair, cartes |
| **Nord2** | `#434C5E` | 67, 76, 94 | Arrière-plan de sélection |
| **Nord3** | `#4C566A` | 76, 86, 106 | Commentaires, texte désactivé |

### Snow Storm (Texte Clair)

Ces couleurs sont utilisées pour le texte et les éléments lumineux.

| Nom | Hex | RVB | Utilisation |
|-----|-----|-----|-------------|
| **Nord4** | `#D8DEE9` | 216, 222, 233 | Texte principal |
| **Nord5** | `#E5E9F0` | 229, 233, 240 | Texte secondaire |
| **Nord6** | `#ECEFF4` | 236, 239, 244 | Texte le plus clair, surbrillances |

### Frost (Bleus)

Les tons bleus fournissent les couleurs d'accent principales.

| Nom | Hex | RVB | Utilisation |
|-----|-----|-----|-------------|
| **Nord7** | `#8FBCBB` | 143, 188, 187 | États de succès |
| **Nord8** | `#88C0D0` | 136, 192, 208 | Accent principal, info |
| **Nord9** | `#81A1C1` | 129, 161, 193 | Liens, accent secondaire |
| **Nord10** | `#5E81AC` | 94, 129, 172 | Accent tertiaire |

### Aurora (Couleurs d'Accent)

Couleurs vibrantes pour les erreurs, avertissements et éléments spéciaux.

| Nom | Hex | RVB | Utilisation |
|-----|-----|-----|-------------|
| **Nord11** | `#BF616A` | 191, 97, 106 | Erreurs, actions destructives |
| **Nord12** | `#D08770` | 208, 135, 112 | Avertissements, annotations |
| **Nord13** | `#EBCB8B` | 235, 203, 139 | Surbrillances, types |
| **Nord14** | `#A3BE8C` | 163, 190, 140 | Succès, méthodes |
| **Nord15** | `#B48EAD` | 180, 142, 173 | Nombres, spécial |

## Utilisation du Thème

### Hiérarchie des Arrière-plans

```
Nord0 (#2E3440)  →  Arrière-plan de fenêtre principal
    ↓
Nord1 (#3B4252)  →  Arrière-plan secondaire, panneaux
    ↓
Nord2 (#434C5E)  →  États de survol, sélections
    ↓
Nord3 (#4C566A)  →  Bordures, séparateurs
```

### Contraste du Texte

```
Nord6 (#ECEFF4)  →  Titres, texte important
    ↓
Nord5 (#E5E9F0)  →  Texte du corps
    ↓
Nord4 (#D8DEE9)  →  Texte secondaire
    ↓
Nord3 (#4C566A)  →  Texte désactivé, espaces réservés
```

### Utilisation des Accents

```
Nord8 (#88C0D0)  →  Boutons principaux, liens
Nord9 (#81A1C1)  →  Boutons secondaires
Nord7 (#8FBCBB)  →  États de succès
Nord14 (#A3BE8C) →  Retour positif
Nord11 (#BF616A) →  Erreurs, destructif
Nord12 (#D08770) →  Avertissements
Nord13 (#EBCB8B) →  Surbrillances
```

## Harmonies de Couleurs

### Monochromatique
Utilisation des variations de Nord0-Nord3 pour la profondeur :
```
Arrière-plan : Nord0
Cartes : Nord1
Élevé : Nord2
Bordures : Nord3
```

### Accents Complémentaires
Association de Frost avec les couleurs Aurora :
```
Primaire : Nord8 (cyan-bleu)
Complément : Nord12 (orange)
```

### Analogue
Couleurs adjacentes pour des transitions douces :
```
Froid : Nord9 → Nord10 (tons bleus)
Chaud : Nord12 → Nord13 (orange-jaune)
```
