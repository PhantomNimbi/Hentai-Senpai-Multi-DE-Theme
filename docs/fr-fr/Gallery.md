## Télécharger les Fonds d'Écran

Tous les fonds d'écran sont disponibles dans le répertoire `wallpapers/` du dépôt. Vous pouvez les télécharger individuellement ou cloner l'ensemble du dépôt pour les obtenir tous.

```bash
# Clonez le dépôt pour obtenir tous les fonds d'écran
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Palette de Couleurs

Le thème utilise la [palette de couleurs Nord](https://www.nordtheme.com/), comprenant :

- **Polar Night** - Couleurs de fond sombres
- **Snow Storm** - Couleurs de texte claires
- **Frost** - Couleurs d'accentuation bleues
- **Aurora** - Couleurs d'accentuation colorées

Consultez la page [Palette de Couleurs](Color-Palette-fr-fr) pour des informations détaillées sur les couleurs.
