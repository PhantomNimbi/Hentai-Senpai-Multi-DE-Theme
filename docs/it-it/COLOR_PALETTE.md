## Colori Nord

### Polar Night (Sfondi Scuri)

I colori di sfondo scuro formano la base dell'estetica scura del tema.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-----|
| **Nord0** | `#2E3440` | 46, 52, 64 | Sfondo primario |
| **Nord1** | `#3B4252` | 59, 66, 82 | Sfondo più chiaro, schede |
| **Nord2** | `#434C5E` | 67, 76, 94 | Sfondo selezione |
| **Nord3** | `#4C566A` | 76, 86, 106 | Commenti, testo disabilitato |

### Snow Storm (Testo Chiaro)

Questi colori sono usati per testo ed elementi luminosi.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-----|
| **Nord4** | `#D8DEE9` | 216, 222, 233 | Testo primario |
| **Nord5** | `#E5E9F0` | 229, 233, 240 | Testo secondario |
| **Nord6** | `#ECEFF4` | 236, 239, 244 | Testo più chiaro, highlight |

### Frost (Blu)

I toni blu forniscono i colori accento principali.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-----|
| **Nord7** | `#8FBCBB` | 143, 188, 187 | Stati di successo |
| **Nord8** | `#88C0D0` | 136, 192, 208 | Accento primario, info |
| **Nord9** | `#81A1C1` | 129, 161, 193 | Link, accento secondario |
| **Nord10** | `#5E81AC` | 94, 129, 172 | Accento terziario |

### Aurora (Colori Accento)

Colori vibranti per errori, avvisi ed elementi speciali.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-----|
| **Nord11** | `#BF616A` | 191, 97, 106 | Errori, azioni distruttive |
| **Nord12** | `#D08770` | 208, 135, 112 | Avvisi, annotazioni |
| **Nord13** | `#EBCB8B` | 235, 203, 139 | Highlight, tipi |
| **Nord14** | `#A3BE8C` | 163, 190, 140 | Successo, metodi |
| **Nord15** | `#B48EAD` | 180, 142, 173 | Numeri, speciale |

## Uso Tema

### Gerarchia Sfondi

```
Nord0 (#2E3440)  →  Sfondo finestra principale
    ↓
Nord1 (#3B4252)  →  Sfondo secondario, pannelli
    ↓
Nord2 (#434C5E)  →  Stati hover, selezioni
    ↓
Nord3 (#4C566A)  →  Bordi, divisori
```

### Contrasto Testo

```
Nord6 (#ECEFF4)  →  Titoli, testo importante
    ↓
Nord5 (#E5E9F0)  →  Testo corpo
    ↓
Nord4 (#D8DEE9)  →  Testo secondario
    ↓
Nord3 (#4C566A)  →  Testo disabilitato, placeholder
```

### Uso Accento

```
Nord8 (#88C0D0)  →  Pulsanti primari, link
Nord9 (#81A1C1)  →  Pulsanti secondari
Nord7 (#8FBCBB)  →  Stati di successo
Nord14 (#A3BE8C) →  Feedback positivo
Nord11 (#BF616A) →  Errori, distruttivo
Nord12 (#D08770) →  Avvisi
Nord13 (#EBCB8B) →  Highlight
```

## Armonie Colori

### Monocromatico
Uso di variazioni di Nord0-Nord3 per profondità:
```
Sfondo: Nord0
Schede: Nord1
Elevato: Nord2
Bordi: Nord3
```

### Accenti Complementari
Abbinamento di Frost con colori Aurora:
```
Primario: Nord8 (ciano-blu)
Complementare: Nord12 (arancione)
```

### Analogo
Colori adiacenti per transizioni morbide:
```
Freddo: Nord9 → Nord10 (toni blu)
Caldo: Nord12 → Nord13 (arancione-giallo)
```
