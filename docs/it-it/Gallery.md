## Scaricare gli Sfondi

Tutti gli sfondi sono disponibili nella directory `wallpapers/` del repository. Puoi scaricarli individualmente o clonare l'intero repository per ottenerli tutti.

```bash
# Clona il repository per ottenere tutti gli sfondi
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Palette di Colori

Il tema utilizza la [palette di colori Nord](https://www.nordtheme.com/), che comprende:

- **Polar Night** - Colori di sfondo scuri
- **Snow Storm** - Colori di testo chiari
- **Frost** - Colori di accento blu
- **Aurora** - Colori di accento colorati

Consulta la pagina [Palette di Colori](Color-Palette-it-it) per informazioni dettagliate sui colori.
