## Scarica gli Sfondi

Tutti gli sfondi sono disponibili nella directory `wallpapers/` del repository. Puoi scaricarli singolarmente o clonare l'intero repository per ottenerli tutti.

```bash
# Clona il repository per ottenere tutti gli sfondi
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Palette dei Colori

Il tema utilizza la [palette dei colori Nord](https://www.nordtheme.com/), che comprende:

- **Polar Night** - Colori di sfondo scuri
- **Snow Storm** - Colori del testo chiari
- **Frost** - Colori di accento blu
- **Aurora** - Colori di accento colorati

Vedi la pagina [Palette dei Colori](Color-Palette-it-it) per informazioni dettagliate sui colori.
