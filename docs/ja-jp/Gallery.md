## 壁紙のダウンロード

すべての壁紙は、リポジトリの `wallpapers/` ディレクトリで利用可能です。個別にダウンロードするか、リポジトリ全体をクローンしてすべて入手することができます。

```bash
# すべての壁紙を取得するためにリポジトリをクローンする
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## カラーパレット

このテーマは [Nord カラーパレット](https://www.nordtheme.com/)を使用しており、以下を含みます：

- **Polar Night** - ダークな背景色
- **Snow Storm** - 明るいテキスト色
- **Frost** - ブルーのアクセント色
- **Aurora** - カラフルなアクセント色

詳細な色情報については [カラーパレット](Color-Palette-ja-jp) ページを参照してください。
