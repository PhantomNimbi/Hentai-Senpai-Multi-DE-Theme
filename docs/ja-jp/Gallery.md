## 壁紙のダウンロード

すべての壁紙はリポジトリの `wallpapers/` ディレクトリで利用できます。個別にダウンロードするか、リポジトリ全体をクローンしてすべてを取得できます。

```bash
# すべての壁紙を取得するためにリポジトリをクローン
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## カラーパレット

このテーマは [Nord カラーパレット](https://www.nordtheme.com/)を使用しています：

- **Polar Night** - 暗い背景色
- **Snow Storm** - 明るいテキスト色
- **Frost** - 青いアクセント色
- **Aurora** - カラフルなアクセント色

詳細なカラー情報については、[カラーパレット](Color-Palette-ja-jp) ページをご覧ください。
