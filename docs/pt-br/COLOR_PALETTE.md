## Cores Nord

### Polar Night (Fundos Escuros)

As cores de fundo escuro formam a base da estética dark do tema.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord0** | `#2E3440` | 46, 52, 64 | Fundo principal |
| **Nord1** | `#3B4252` | 59, 66, 82 | Fundo mais claro, cartões |
| **Nord2** | `#434C5E` | 67, 76, 94 | Fundo de seleção |
| **Nord3** | `#4C566A` | 76, 86, 106 | Comentários, texto secundário |

### Snow Storm (Texto Claro)

Estas cores são usadas para texto e elementos brilhantes.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord4** | `#D8DEE9` | 216, 222, 233 | Texto principal |
| **Nord5** | `#E5E9F0` | 229, 233, 240 | Texto secundário |
| **Nord6** | `#ECEFF4` | 236, 239, 244 | Texto mais brilhante, destaques |

### Frost (Azuis)

Os tons de azul fornecem as cores de destaque principais.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord7** | `#8FBCBB` | 143, 188, 187 | Estados de sucesso |
| **Nord8** | `#88C0D0` | 136, 192, 208 | Destaque principal, informação |
| **Nord9** | `#81A1C1` | 129, 161, 193 | Links, destaque secundário |
| **Nord10** | `#5E81AC` | 94, 129, 172 | Destaque terciário |

### Aurora (Cores de Destaque)

Cores vibrantes para erros, avisos e elementos especiais.

| Nome | Hex | RGB | Uso |
|------|-----|-----|-------|
| **Nord11** | `#BF616A` | 191, 97, 106 | Erros, ações destrutivas |
| **Nord12** | `#D08770` | 208, 135, 112 | Avisos, anotações |
| **Nord13** | `#EBCB8B` | 235, 203, 139 | Destaques, tipos |
| **Nord14** | `#A3BE8C` | 163, 190, 140 | Sucesso, métodos |
| **Nord15** | `#B48EAD` | 180, 142, 173 | Números, especial |

## Uso no Tema

### Hierarquia de Fundos

```
Nord0 (#2E3440)  →  Fundo da janela principal
    ↓
Nord1 (#3B4252)  →  Fundo secundário, painéis
    ↓
Nord2 (#434C5E)  →  Estados de hover, seleções
    ↓
Nord3 (#4C566A)  →  Bordas, divisores
```

### Contraste de Texto

```
Nord6 (#ECEFF4)  →  Títulos, texto importante
    ↓
Nord5 (#E5E9F0)  →  Texto do corpo
    ↓
Nord4 (#D8DEE9)  →  Texto secundário
    ↓
Nord3 (#4C566A)  →  Texto desabilitado, placeholders
```

### Uso de Destaques

```
Nord8 (#88C0D0)  →  Botões primários, links
Nord9 (#81A1C1)  →  Botões secundários
Nord7 (#8FBCBB)  →  Estados de sucesso
Nord14 (#A3BE8C) →  Feedback positivo
Nord11 (#BF616A) →  Erros, destrutivo
Nord12 (#D08770) →  Avisos
Nord13 (#EBCB8B) →  Destaques
```

## Harmonias de Cores

### Monocromático
Usando variações de Nord0-Nord3 para profundidade:
```
Fundo: Nord0
Cartões: Nord1
Elevado: Nord2
Bordas: Nord3
```

### Complementares
Pareando Frost com cores Aurora:
```
Primário: Nord8 (ciano-azul)
Complemento: Nord12 (laranja)
```

### Análogas
Cores adjacentes para transições suaves:
```
Frias: Nord9 → Nord10 (tons de azul)
Quentes: Nord12 → Nord13 (laranja-amarelo)
```
