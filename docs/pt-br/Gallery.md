## Baixar Papéis de Parede

Todos os papéis de parede estão disponíveis no diretório `wallpapers/` do repositório. Você pode baixá-los individualmente ou clonar o repositório inteiro para obtê-los todos.

```bash
# Clone o repositório para obter todos os papéis de parede
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Paleta de Cores

O tema utiliza a [paleta de cores Nord](https://www.nordtheme.com/), apresentando:

- **Polar Night** - Cores de fundo escuras
- **Snow Storm** - Cores de texto claras
- **Frost** - Cores de destaque azuis
- **Aurora** - Cores de destaque coloridas

Veja a página [Paleta de Cores](Color-Palette-pt-br) para informações detalhadas sobre as cores.
