## Как внести вклад

Есть много способов внести вклад в этот проект:

1. **Сообщать об ошибках** - Нашли проблему? Дайте нам знать!
2. **Предлагать функции** - Есть идея? Мы будем рады услышать!
3. **Отправлять исправления** - Улучшения кода всегда приветствуются
4. **Улучшать документацию** - Помогите сделать документы понятнее
5. **Переводить** - Помогите сделать тему доступной глобально
6. **Делиться** - Распространяйте информацию о теме

### Рабочий процесс вклада

1. **Сделайте форк репозитория** на GitHub
2. **Создайте новую ветку** для вашей функции/исправления:
   ```bash
   git checkout -b feature/my-new-feature
   # или
   git checkout -b fix/issue-description
   ```
3. **Внесите свои изменения** с чёткими, сфокусированными коммитами
4. **Тщательно протестируйте** свои изменения
5. **Отправьте Pull Request** с чётким описанием

## Сообщение о проблемах

### Перед сообщением

- [ ] Поищите существующие [issues](https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme/issues), чтобы избежать дубликатов
- [ ] Проверьте, существует ли проблема в последней версии
- [ ] Попробуйте изолировать проблему

### Создание отчёта об ошибке

Включите следующую информацию:

| Поле | Описание |
|------|----------|
| **Заголовок** | Чёткий, описательный заголовок |
| **Описание** | Подробное описание проблемы |
| **Шаги воспроизведения** | Пронумерованные шаги для воспроизведения ошибки |
| **Ожидаемое поведение** | Что должно произойти |
| **Фактическое поведение** | Что происходит на самом деле |
| **Скриншоты** | Визуальные доказательства (если применимо) |
| **Информация о системе** | ОС, DE/WM, версия GTK |

### Пример шаблона отчёта об ошибке

```markdown
**Описание:**
Тема не применяется к приложениям GTK4

**Шаги воспроизведения:**
1. Установите тему с помощью `./install.sh`
2. Откройте приложение GTK4 (например, Текстовый редактор GNOME)
3. Наблюдайте стиль Adwaita по умолчанию

**Ожидаемое:**
Приложение должно использовать тему Hentai-Senpai

**Фактическое:**
Приложение использует тему Adwaita по умолчанию

**Система:**
- ОС: Ubuntu 22.04
- DE: GNOME 42
- GTK: 4.6
```

## Стиль кода

### CSS/Стилизация

- Используйте 2 пробела для отступов
- Группируйте связанные свойства
- Используйте осмысленные имена переменных
- Комментируйте сложные разделы

Пример:
```css
/* Стилизация основной кнопки */
button.primary {
  background-color: @accent_color;
  color: @fg_color;
  border-radius: 6px;
  padding: 8px 16px;
  
  /* Состояние наведения */
  &:hover {
    background-color: @accent_hover_color;
  }
}
```

### Shell-скрипты

- Используйте shebang `#!/bin/bash`
- Заключайте все переменные в кавычки: `"$variable"`
- Используйте осмысленные имена функций
- Добавляйте комментарии для сложной логики

### Сообщения коммитов

Следуйте формату conventional commits:

```
type(scope): subject

body (опционально)

footer (опционально)
```

**Типы:**
- `feat`: Новая функция
- `fix`: Исправление ошибки
- `docs`: Изменения документации
- `style`: Изменения стиля кода (форматирование)
- `refactor`: Рефакторинг кода
- `test`: Добавление или обновление тестов
- `chore`: Задачи обслуживания

**Примеры:**
```
feat(gtk3): добавить поддержку скруглённых углов
fix(install): исправить проблему пути на Fedora
docs(readme): обновить инструкции по установке
```

## Документация

### Улучшение документации

Улучшения документации высоко ценятся! Вы можете:

- Исправлять опечатки и грамматику
- Добавлять примеры и скриншоты
- Прояснять запутанные разделы
- Добавлять недостающую информацию
- Переводить на другие языки

### Структура документации

```
docs/
├── INSTALLATION.md      # Руководство по установке
├── TROUBLESHOOTING.md   # Устранение неполадок
├── CUSTOMIZATION.md     # Руководство по настройке
├── COLOR_PALETTE.md     # Справочник по цветам
└── CONTRIBUTING.md      # Этот файл
```

### Добавление скриншотов

При добавлении визуальной документации:

1. Используйте формат PNG для скриншотов
2. Держите размер файлов разумным (< 500KB)
3. Используйте описательные имена файлов
4. Сфокусируйтесь на конкретной функции

## Переводы

### Перевод документации

Чтобы добавить перевод на новый язык:

1. **Скопируйте английские файлы:**
   ```bash
   cp docs/INSTALLATION.md docs/INSTALLATION-ru.md
   ```

2. **Переведите содержимое** в новом файле

3. **Обновите панель перевода** в рабочем процессе:
   - Отредактируйте `.github/workflows/generate-wiki.yml`
   - Добавьте новый язык в панель перевода Home.md

4. **Поддерживаемые языковые коды:**
   | Код | Язык |
   |-----|------|
   | `pt` | Португальский |
   | `es` | Испанский |
   | `fr` | Французский |
   | `de` | Немецкий |
   | `it` | Итальянский |
   | `ja` | Японский |
   | `zh` | Китайский |

### Советы по переводу

- Сохраняйте технические термины на английском, если нет прямого перевода
- Поддерживайте ту же структуру markdown
- Обновляйте ссылки для указания на переведённые страницы
- Тестируйте отображение перед отправкой

## Настройка разработки

### Требования

```bash
# Установите необходимые инструменты
sudo apt install git sassc inkscape optipng
```

### Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme

# Установка зависимостей
# (см. раздел Требования выше)

# Сборка темы
./install.sh

# Локальное тестирование
./apply-theme.sh
```

### Структура проекта

```
Hentai-Senpai-GTK-Theme/
├── src/                    # Исходные файлы
│   ├── gtk-2.0/           # Тема GTK2
│   ├── gtk-3.0/           # Тема GTK3
│   ├── gtk-4.0/           # Тема GTK4
│   ├── gnome-shell/       # Тема GNOME Shell
│   ├── cinnamon/          # Тема Cinnamon
```
