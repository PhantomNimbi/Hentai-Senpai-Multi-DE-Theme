## Скачать обои

Все обои доступны в директории `wallpapers/` репозитория. Вы можете скачать их по отдельности или клонировать весь репозиторий, чтобы получить их все.

```bash
# Клонируйте репозиторий, чтобы получить все обои
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## Цветовая палитра

Тема использует [цветовую палитру Nord](https://www.nordtheme.com/), включающую:

- **Polar Night** - Темные цвета фона
- **Snow Storm** - Светлые цвета текста
- **Frost** - Синие акцентные цвета
- **Aurora** - Красочные акцентные цвета

См. страницу [Цветовая палитра](Color-Palette-ru-ru) для подробной информации о цветах.
