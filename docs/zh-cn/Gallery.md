## 下载壁纸

所有壁纸都可以在仓库的 `wallpapers/` 目录中找到。您可以单独下载它们，或者克隆整个仓库以获取所有壁纸。

```bash
# 克隆仓库以获取所有壁纸
git clone https://github.com/PhantomNimbi/Hentai-Senpai-GTK-Theme.git
cd Hentai-Senpai-GTK-Theme/wallpapers
```

## 配色方案

该主题使用 [Nord 配色方案](https://www.nordtheme.com/)，包括：

- **Polar Night** - 深色背景色
- **Snow Storm** - 浅色文本色
- **Frost** - 蓝色强调色
- **Aurora** - 彩色强调色

有关详细的颜色信息，请参阅[配色方案](Color-Palette-zh-cn)页面。
