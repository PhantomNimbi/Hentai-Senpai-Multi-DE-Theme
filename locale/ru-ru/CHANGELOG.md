## [Не Выпущено]

### Добавлено

- **Шаблоны GitHub Issue**
  - Шаблон отчета об ошибке с контрольным списком окружения
  - Шаблон запроса функции с разделами вариантов использования
  - Шаблон вопросов/поддержки
  - Файл конфигурации со ссылками для связи
- **Руководство по Вкладу**
  - Подробный `docs/CONTRIBUTING.md`, включающий:
    - Инструкции по настройке разработки
    - Руководства по стилю кода для CSS и shell-скриптов
    - Соглашения о сообщениях коммитов
    - Процесс pull request
    - Процедуры тестирования
    - Руководства сообщества
- **Улучшенная Документация**
  - Добавлен `docs/HOME.md` как подробная стартовая страница документации
  - Упрощен `docs/README.md` для легкой навигации
  - Обновлены все файлы документации с последовательным форматированием и перекрестными ссылками
- **Поддержка Переводов**
  - Добавлена панель перевода ко всем markdown-файлам документации
  - Поддержка 9 языков: Английский, Японский, Испанский, Французский, Немецкий, Китайский, Корейский, Русский, Португальский
- **Интеграция с Социальными Сетями**
  - Кнопки поделиться для Twitter/X, Reddit, Facebook, LinkedIn, Mastodon и Telegram
  - Значки статуса, показывающие версию, лицензию, звезды, участников и issues
- **Многоязычная Документация**
  - Реструктурирована docs в папки на основе локалей (en-us, pt-br, es-es, fr-fr, de-de, it-it, ja-jp, zh-cn, ru-ru)
  - Полные переводы на 9 языков
  - Выпадающие списки выбора языка на всех страницах документации
  - Обновлен workflow GitHub Actions для поддержки всех 9 языков
- **Страница Галереи**
  - Создана Gallery.md, демонстрирующая предварительные просмотры темы и обои
  - Отображает изображения preview-1.png и preview-2.png
  - Показывает все 6 доступных обоев
  - Доступна на всех 9 языках
  - Исправлено: Фактически созданы файлы Gallery.md во всех папках локалей
  - Исправлено: Исправлено назначение изображений предпросмотра (preview-2.png = Рабочий стол, preview-1.png = Приложения)
  - Исправлено: Исправлено описание обоев (минималистичные, монохромные цвета, темы ecchi)
- **GitHub Discussions**
  - Созданы обширные категории обсуждений: Общее, Витрина, Вопросы и ответы, Идеи, Разработка, Объявления
  - Добавлены шаблоны обсуждений для каждой категории
  - Создан DISCUSSION_GUIDE.md с инструкциями по использованию
  - Определены лучшие практики и руководства сообщества
  - Перемещено в отдельную ветку `discussions` для управления шаблонами
  - Создан workflow setup-discussions.yml для генерации постов из шаблонов

- **Изображения Предпросмотра**: Удалены SVG-изображения предпросмотра, оставлены только PNG-предпросмотры
- **Wiki Workflow**: Обновлен для обработки структуры документации на основе локалей с 9 языками
- **Организация Скриптов**: Переименован `apply-theme.sh` в `apply.sh` и перемещен в директорию `scripts/`
  - Обновлены все ссылки в документации и коде
  - Консолидированы все скрипты в директории `scripts/`

## [1.0.0] - 2026-05-03

### Добавлено

- **Первоначальный релиз** Hentai-Senpai Theme
- Полная поддержка темы GTK:
  - GTK 2.0 с полным стилем виджетов и ресурсами
  - GTK 3.0 с полным CSS-темингом
  - GTK 4.0 с современным CSS и пользовательскими свойствами
- **GNOME Shell 40+** полная тема, включая:
  - Стилизация панели с поддержкой прозрачности
  - Теминг обзора и сетки приложений
  - Стилизация уведомлений и календаря
  - Системные меню и всплывающие окна
  - Предпросмотр окон и alt-tab
- Поддержка среды рабочего стола **Cinnamon** с темингом панели и меню
- Тема оконного менеджера **XFWM4**
- Поддержка оконных украшений **Metacity**
- Интеграция **палитры цветов Nord**:
  - Фоны **Polar Night** (`#2e3440`, `#3b4252`, `#434c5e`, `#4c566a`)
  - Цвета текста **Snow Storm** (`#d8dee9`, `#e5e9f0`, `#eceff4`)
  - Акцентные цвета **Frost** (`#8fbcbb`, `#88c0d0`, `#81a1c1`, `#5e81ac`)
  - Семантические цвета **Aurora** (`#bf616a`, `#d08770`, `#ebcb8b`, `#a3be8c`, `#b48ead`)
- Принципы **Material Design**:
  - Скругленные углы 12px для кнопок, карточек и полей ввода
  - Радиус границы 20px для всплывающих окон
  - Круглые чекбоксы и радио-кнопки (радиус 9999px)
  - Тени возвышения и эффекты глубины
  - Эффекты пульсации на интерактивных элементах
- **Скрипт установки** (`install.sh`) с комплексными опциями:
  - Функциональность установки и удаления
  - Возможность обновления/переустановки
  - Пользовательские опции назначения и имени
  - Исправление Libadwaita для приложений GTK4
  - Исправление темы Flatpak для песочничных приложений
  - Стилизация темы дока (прозрачные и сплошные варианты)
  - Установка обоев
  - Проверка зависимостей с авто-установкой
  - Отображение информации о системе и совместимости
- **Скрипт применения темы** (`scripts/apply.sh`) для автоматической активации темы
- **Прозрачная тема дока Plank** с правильной интеграцией цветов Nord
- **Подробная документация**:
  - Руководство по установке с подробными опциями
  - Руководство по устранению неполадок для распространенных проблем
  - Справочник палитры цветов с примерами использования
  - Руководство по настройке для персонализации темы
- **Коллекция обоев** с дизайнами, вдохновленными Nord

### Компоненты Темы

| Компонент | Описание |
|-----------|-------------|
| **GTK 2.0** | Полный стиль виджетов с изображениями-ресурсами |
| **GTK 3.0** | Полный CSS-теминг со всеми виджетами |
| **GTK 4.0** | Современный CSS с пользовательскими свойствами и переменными |
| **GNOME Shell** | Полная тема оболочки со всеми элементами UI |
| **Cinnamon** | Теминг рабочего стола и панели |
| **XFWM4** | Оконные украшения для XFCE |
| **Metacity** | Оконные украшения для MATE и других |
| **Plank** | Прозрачная тема дока |
